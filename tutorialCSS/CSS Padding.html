CSS Padding

What is Padding?

• Padding creates space inside an element's border.
• It's between the content and the border.
• Adds breathing room inside elements.

Individual Sides

div {
  padding-top: 20px;
  padding-right: 30px;
  padding-bottom: 20px;
  padding-left: 30px;
}

Shorthand Property

/* All sides */
div { padding: 20px; }

/* Top/Bottom, Left/Right */
div { padding: 20px 30px; }

/* Top, Left/Right, Bottom */
div { padding: 10px 20px 30px; }

/* Top, Right, Bottom, Left */
div { padding: 10px 20px 30px 40px; }

Box Model

div {
  width: 300px;
  padding: 20px;
  border: 2px solid black;
  margin: 10px;
}

Total width = 300px + 40px padding + 4px border + 20px margin = 364px

box-sizing: border-box

div {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid black;
}

Padding and border are included in the width/height.
