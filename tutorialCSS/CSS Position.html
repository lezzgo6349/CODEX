CSS Position

Position Values

• static - default positioning
• relative - relative to normal position
• absolute - relative to nearest positioned parent
• fixed - relative to viewport
• sticky - hybrid of relative and fixed

Static (Default)

div { position: static; }

Elements are positioned in normal document flow.

Relative

div {
  position: relative;
  top: 20px;
  left: 30px;
}

Positioned relative to its normal position.

Absolute

div {
  position: absolute;
  top: 50px;
  right: 10px;
}

Positioned relative to nearest positioned ancestor.

Fixed

div {
  position: fixed;
  bottom: 0;
  width: 100%;
}

Positioned relative to the viewport (stays in place when scrolling).

Sticky

div {
  position: sticky;
  top: 0;
}

Switches between relative and fixed based on scroll position.

Positioning Properties

element {
  position: absolute;
  top: 10px;
  right: 20px;
  bottom: 30px;
  left: 40px;
}
