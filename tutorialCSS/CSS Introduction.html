Styling the Web with CSS

What is CSS?

• CSS stands for Cascading Style Sheets
• CSS describes how HTML elements are displayed on the screen.
• CSS saves a lot of work — it can control the layout of multiple web pages all at once.
• External stylesheets are stored in .css files.
• CSS works hand in hand with HTML to make web pages attractive and responsive.

Why Use CSS?

• Separate content (HTML) from presentation (CSS).
• Improve consistency and maintainability of web design.
• Make web pages load faster and look professional.
• Easily adapt websites to different screen sizes and devices.

Three Ways to Apply CSS

1. Inline CSS: applied directly to an element using the style attribute.
2. Internal CSS: defined inside a <style> tag within the HTML file.
3. External CSS: written in a separate .css file and linked via <link>.

CSS Syntax

CSS is made up of selectors and declaration blocks.
A declaration block contains one or more declarations separated by semicolons.

Example: 

h1 {
  color: blue;
  text-align: center;
}

How Browsers Apply CSS

• Browsers read CSS rules and apply them from top to bottom.
• When multiple rules apply to the same element, the one with higher specificity wins.
• CSS “cascades” — newer rules can override earlier ones.
