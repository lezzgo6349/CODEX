CSS Lists

List Properties

• list-style-type - bullet style
• list-style-image - custom bullets
• list-style-position - inside/outside

List Style Type

ul { list-style-type: square; }
ol { list-style-type: lower-roman; }

Values: disc, circle, square, decimal, lower-roman, upper-roman, none

Custom Bullets

ul { list-style-image: url('small.gif'); }

List Position

ul { list-style-position: inside; }
ul { list-style-position: outside; }

Remove List Markers

ul { list-style: none; }

List Style Shorthand

ul { list-style: square inside url('small.gif'); }

Format: type position image

Styled Lists Example

ul {
  list-style-type: none;
  padding: 0;
}
li {
  background: #f0f0f0;
  margin: 5px;
  padding: 10px;
}
