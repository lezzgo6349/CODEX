CSS Responsive Design

What is Responsive Design?

• Makes web pages look good on all devices
• Adapts layout for desktops, tablets, and phones
• Uses flexible layouts, images, and media queries

Viewport Meta Tag

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Controls page dimensions and scaling.

Media Queries

@media only screen and (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

Apply styles based on screen size.

Flexible Units

div {
  width: 100%;  /* Percentage */
  font-size: 2vw;  /* Viewport width */
  padding: 2em;  /* Relative to font */
}

Responsive Images

img {
  max-width: 100%;
  height: auto;
}

Images scale to fit container.

Flexbox for Responsive

.container {
  display: flex;
  flex-direction: column;
}

@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

Grid for Responsive

.container {
  display: grid;
  grid-template-columns: 1fr;
}

@media (min-width: 768px) {
  .container {
    grid-template-columns: repeat(3, 1fr);
  }
}
