CSS Selectors

What are CSS Selectors?

• CSS selectors are patterns used to select and style HTML elements.
• Selectors are used to target specific elements on a webpage.
• Different types of selectors allow precise control over styling.

Element Selector

Selects all elements of a specific type.

p {
  color: blue;
}

This targets all <p> elements and makes them blue.

ID Selector

Selects an element with a specific ID attribute.

#header {
  background-color: gray;
}

Targets the element with id="header". Use # followed by the ID name.

Class Selector

Selects all elements with a specific class attribute.

.highlight {
  color: yellow;
}

Targets all elements with class="highlight". Use . followed by the class name.

Descendant Selector

Selects elements that are descendants of another element.

div p {
  margin: 10px;
}

Targets all <p> elements inside <div> elements.

Child Selector

Selects direct children of an element.

div > p {
  color: red;
}

Targets only direct child <p> elements of <div>.

Attribute Selector

Selects elements based on attributes.

input[type="text"] {
  border: 1px solid blue;
}

Targets all text inputs.

Pseudo-class Selectors

Select elements in a specific state.

a:hover {
  color: green;
}
button:active {
  background: darkblue;
}

Common pseudo-classes: :hover, :active, :focus, :first-child, :nth-child().
