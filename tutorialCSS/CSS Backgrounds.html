CSS Backgrounds

Background Properties

• background-color - sets the background color.
• background-image - sets one or more images.
• background-repeat - how the image is repeated.
• background-position - position of the image.
• background-size - size of the background image.

Background Color

body { background-color: lightblue; }
div { background-color: #ffffff; }

Background Image

body {
  background-image: url('pattern.png');
}

Background Repeat

body {
  background-image: url('tile.png');
  background-repeat: repeat; /* default */
  background-repeat: no-repeat;
  background-repeat: repeat-x;
  background-repeat: repeat-y;
}

Background Position

body {
  background-position: center top;
  background-position: 50% 50%;
  background-position: left bottom;
  background-repeat: no-repeat;
}


Background Shorthand

div {
  background: color url('image.jpg') repeat position;
}
body { background: #fff url('bg.png') no-repeat center; }
