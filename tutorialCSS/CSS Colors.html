CSS Colors

CSS Color Values

• CSS supports multiple ways to specify colors.
• Color names, hex codes, RGB, RGBA, HSL, and HSLA values.
• Each method has different use cases.

Named Colors

Use predefined color names.

h1 { color: blue; }
div { background-color: tomato; }

Common names: red, blue, green, yellow, black, white, gray, purple, orange, pink.

Hexadecimal Colors

Use 6-digit hex codes starting with #.

h1 { color: #FF5733; }
div { background: #2E4057; }

Format: #RRGGBB where RR, GG, BB are hex values (00-FF).

RGB Colors

Use red, green, blue values (0-255).

h1 { color: rgb(255, 87, 51); }
div { background: rgb(46, 64, 87); }

Each value ranges from 0 to 255.

RGBA Colors

RGB with alpha (transparency) channel (0-1).

div { background: rgba(255, 87, 51, 0.5); }

The fourth value controls opacity: 0 = transparent, 1 = opaque.

HSL Colors

Hue, Saturation, Lightness.

h1 { color: hsl(9, 100%, 60%); }

Hue (0-360), Saturation % (0-100), Lightness % (0-100).

Color Properties

 body { color: navy; }
p { background-color: yellow; }
a { color: red; }
button { border-color: green; }

• color - text color
• background-color - background color
• border-color - border color
• outline-color - outline color
