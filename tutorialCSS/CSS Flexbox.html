CSS Flexbox

What is Flexbox?

• Flexbox is a layout method for arranging items in rows or columns
• Makes it easy to create flexible, responsive layouts
• Perfect for aligning and distributing space among items

Flex Container

.container {
  display: flex;
}

Creates a flex container.

Flex Direction

.container {
  display: flex;
  flex-direction: row;    /* default */
  flex-direction: column;
  flex-direction: row-reverse;
  flex-direction: column-reverse;
}

Justify Content

.container {
  display: flex;
  justify-content: center;    /* center items */
  justify-content: flex-start; /* start */
  justify-content: flex-end;   /* end */
  justify-content: space-between;
  justify-content: space-around;
  justify-content: space-evenly;
}

Align Items

.container {
  display: flex;
  align-items: center;
  align-items: flex-start;
  align-items: flex-end;
  align-items: stretch;
}

Flex Wrap

.container {
  display: flex;
  flex-wrap: wrap;
}

Allows items to wrap to next line.

Flex Items Properties

.item {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: auto;
  /* Shorthand */
  flex: 1;
}
