Understanding CSS Syntax

What is CSS Syntax?

• CSS syntax is the structure and rules for writing CSS code.
• A CSS rule consists of a selector and a declaration block.
• The declaration block contains one or more declarations.
• Each declaration consists of a property and a value, separated by a colon.

Basic CSS Syntax Structure

selector {
  property: value;
}

• Selector: points to the HTML element you want to style.
• Property: the style attribute you want to change.
• Value: the value for the property.
• The declaration block is enclosed in curly braces {}.

Example

h1 {
  color: blue;
  font-size: 30px;
}

This CSS rule targets <h1> elements and applies:
• Blue color to the text.
• Font size of 30 pixels.

CSS Declaration Rules

• Each property-value pair is called a declaration.
• Declarations must be separated by a semicolon ;.
• Multiple declarations can be in the same rule.
• Use a colon : to separate property from value.
• CSS is case-sensitive - property names are lowercase.

Multi-Declaration Example

p {
  color: red;
  text-align: center;
  font-size: 16px;
  margin: 10px;
}

This example shows how to apply multiple styles to paragraph <p> elements at once.

CSS Comments

• Comments are used to explain your CSS code.
• Comments are ignored by the browser and help with documentation.
• Use /* */ to create comments in CSS. 

/* This is a CSS comment */
h1 {
  color: blue; /* Comments can also be inline */
}

CSS Value Types

• Keywords: pre-defined values like blue, center.
• Numbers: with or without units (e.g., 16px, 2em).
• Percentages: relative values (e.g., 50%).
• Colors: named colors, hex codes, RGB values.
• URLs: paths to external resources (e.g., url('image.jpg')).

Common CSS Units

• px (pixels) - absolute size.
• % (percentage) - relative to parent element.
• em - relative to font-size of element.
• rem - relative to root element's font-size.
• vh/vw - viewport height/width. 

.example {
  width: 100%;        /* Percentage */
  height: 300px;      /* Pixels */
  font-size: 1.5em;   /* Em units */
  padding: 2rem;      /* Rem units */
}
