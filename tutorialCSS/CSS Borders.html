CSS Borders

Border Properties

• border-width - thickness of the border.
• border-style - style of the border.
• border-color - color of the border.

Border Width

p {
   border-width: 5px;
   border-style: dashed;
}
div {
  border-width: thin;
  border-style: solid;
}

Border Style

div { border-style: solid; }
p { border-style: dashed; }
h1 { border-style: dotted; }

Common styles: solid, dashed, dotted, double, groove, ridge, inset, outset, none, hidden.

Border Color

div {
  border-color: red;
  border-style: double;
}
p {
  border-color: #0000ff;
  border-style: outset;
}

Border Shorthand

            
  div { border: 2px solid black; }

Combines width, style, and color.

Individual Side Borders

div {
  border-top: 1px solid red;
  border-right: 2px dashed blue;
  border-bottom: 3px dotted green;
  border-left: 4px double orange;
}

Border Radius (Rounded)

div {
  border-radius: 10px;
  border-style: solid;
  border-color: pink;
}
button { border-radius: 50%; }
