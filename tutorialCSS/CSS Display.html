CSS Display

Display Values

• block - takes full width, new line
• inline - only takes necessary width
• inline-block - inline with block properties
• none - hides element completely
• flex - flexbox container
• grid - grid container

Block Elements

div { display: block; }
p { display: block; }

Inline Elements

span { display: inline; }
a { display: inline; }

Inline-Block

button { display: inline-block; }
img { display: inline-block; }

Allows width/height like block, but displays inline.

Hide Elements

.hidden { display: none; }

Removes element from the layout entirely.

Flex Display

div { display: flex; }

Grid Display

div { display: grid; }
