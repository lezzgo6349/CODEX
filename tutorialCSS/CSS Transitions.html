CSS Transitions

What are CSS Transitions?

• Transitions smoothly change from one state to another
• Create smooth effects when properties change
• Often used with :hover and :active pseudo-classes

Transition Property

div {
  transition-property: background-color;
  transition-duration: 2s;
}

Specifies which property to animate.

Transition Duration

div {
  transition-duration: 1s;
  transition-duration: 500ms;
}

How long the transition takes.

Transition Timing Function

div {
  transition-timing-function: ease;
  transition-timing-function: linear;
  transition-timing-function: ease-in;
  transition-timing-function: ease-out;
}

Transition Delay

div {
  transition-delay: 0.5s;
}

Delay before transition starts.

Transition Shorthand

div {
  transition: background-color 1s ease 0.5s;
}
div {
  transition: all 0.3s ease;
}

Format: property duration timing-function delay

Example with Hover

div {
  background-color: blue;
  transition: background-color 0.5s;
}
div:hover {
  background-color: red;
}

Color changes smoothly on hover.
