CSS Properties By Category

Layout Properties

display - block, inline, flex, grid
position - static, relative, absolute, fixed
width, height - element dimensions
margin - outer spacing
padding - inner spacing
float - left, right, none

Flexbox Properties

flex-direction - row, column
justify-content - horizontal alignment
align-items - vertical alignment
flex-wrap - wrap items
gap - space between items

Grid Properties

grid-template-columns - column sizes
grid-template-rows - row sizes
grid-gap - grid spacing
grid-column - item column placement
grid-row - item row placement

Typography

font-family - font type
font-size - text size
font-weight - boldness
font-style - italic, normal
text-align - text alignment
line-height - line spacing

Colors & Backgrounds

color - text color
background-color - background
background-image - image background
opacity - transparency

Borders & Effects

border - border style
border-radius - rounded corners
box-shadow - shadow effect
text-shadow - text shadow

Animations & Transitions

animation - CSS animation
transition - CSS transition
transform - rotate, scale, translate
@keyframes - animation sequence
