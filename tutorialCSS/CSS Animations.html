CSS Animations

What are CSS Animations?

• Animations allow elements to gradually change styles
• You can move, rotate, scale, and fade elements
• Create engaging and dynamic web experiences

Keyframes

@keyframes example {
  from { background-color: red; }
  to { background-color: blue; }
}

Defines the animation sequence.

Apply Animation

div {
  animation-name: example;
  animation-duration: 2s;
}

Animation Properties

div {
  animation-name: example;
  animation-duration: 3s;
  animation-delay: 1s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

Animation Shorthand

div {
  animation: example 3s ease 1s infinite alternate;
}

Format: name duration timing-function delay count direction

Multiple Keyframes

@keyframes move {
  0% { left: 0px; }
  50% { left: 100px; }
  100% { left: 200px; }
}

Common Animations

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
@keyframes slide {
  from { transform: translateX(0); }
  to { transform: translateX(100px); }
}
@keyframes rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
