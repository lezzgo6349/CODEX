Learning Web Structure with HTML

HTML Elements

• The HTML element is everything from the start tag to the end tag:

< tagname > Content goes here... < / tagname >

• Example of some HTML elements:

< h1 > This is Heading 1. < / h1 >

< p > This is a paragraph. < / p >

Nested HTML Elements

• Nested HTML Elements is anelement placed inside another element, creating a hierarchical structure.
the outer element is the parent, and the inner element is the child.

• Nesting is fundamental to HTML for organizing content, applying styles, and enabling functionality.
• HTML elements can be nested (this means that elements can contain other elements).

• The following example contains four HTML elements (<html>, <body>, <h1> and <p>):

    <!DOCTYPE html>
    <html>
    <head>
            <title> Title </title>
    </head>
    <body>
           <p> This is a paragraph. </p>
           <h1> This is heading 1 </h1>
    </body>
    </html>
• The <html> tag can be called a nested html element because both the <head> tag and
the <body> tag are inside.

   then, inside the <body> element there are two other elements: <h1> and <p>:

Empty HTML Elements

• HTML elements with no content are called empty elements.

•The <br> tag defines a line break and the <hr> tag defines a horizontal outline line break
  both are an empty element without a closing tag:

<hr>
<p> This is <br> a paragraph </p>
