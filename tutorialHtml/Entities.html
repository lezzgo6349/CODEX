Learning Web Structure with HTML

HTML Entities

HTML entities are characters used to display reserved characters or characters that don't appear on your keyboard.

They start with an ampersand (&) and end with a semicolon (;).

HTML entities ensure your special characters display correctly in browsers.

Why Use HTML Entities?

  • Display reserved characters like <, >, and & that have special meaning in HTML
  • Show characters not available on your keyboard (e.g., copyright symbol ©, trademark ™)
  • Prevent browsers from interpreting characters as HTML code
  • Ensure consistent display across different browsers and character encodings

Common HTML Entities:

  • &lt; or &#60; - Less than sign (<)
  • &gt; or &#62; - Greater than sign (>)
  • &amp; or &#38; - Ampersand (&)
  • &quot; or &#34; - Double quotation mark (")
  • &apos; or &#39; - Single quotation mark (')
  • &nbsp; or &#160; - Non-breaking space
  • &copy; or &#169; - Copyright symbol (©)
  • &reg; or &#174; - Registered trademark (®)
  • &trade; or &#8482; - Trademark symbol (™)
  • &euro; or &#8364; - Euro symbol (€)

Example - Reserved Characters:

      
<p>To display <div> in HTML, use &lt;div&gt;</p>
<p>The company name is Smith &amp; Co.</p>
<p>She said, &quot;Hello, World!&quot;</p>
<p>Price: $10 &lt; $20</p>

Example - Special Characters and Symbols:

      
<p>Copyright &copy; 2024 My Company</p>
<p>Registered trademark&reg; and Trademark&trade;</p>
<p>Price: &euro;50 or &pound;40</p>
<p>Mathematical: 5 &times; 3 = 15, 10 &divide; 2 = 5</p>
<p>Arrows: &larr; &uarr; &rarr; &darr;</p>

Example - Using Non-Breaking Space:

      
<p>First Name    Last Name</p>
<p>Dr. Smith</p>
<p>Line with spaces</p>

Named Entities vs Numeric Entities:

  • Named Entities: Easy to remember (e.g., &copy;, &nbsp;)
  • Numeric Entities: Use numbers (e.g., &#169; for copyright, &#160; for non-breaking space)
  • Numeric entities can use decimal (&#169;) or hexadecimal (&#xA9;) format
  • Both work the same way, but named entities are generally more readable

Important Reserved Characters:

  • Always use &lt; for < in HTML code examples
  • Always use &gt; for > in HTML code examples
  • Always use &amp; when you want to display an actual ampersand
  • Use &quot; or &apos; inside attribute values if needed

Best Practices:

  • Use entities for reserved characters (<, >, &) to avoid HTML parsing issues
  • Use &nbsp; sparingly - prefer CSS for spacing when possible
  • Prefer named entities over numeric ones for better code readability
  • Ensure proper encoding (UTF-8) in your HTML document to support all characters
  • Test special characters across different browsers to ensure compatibility
  • Use semantic HTML5 entities for common symbols and currency signs
