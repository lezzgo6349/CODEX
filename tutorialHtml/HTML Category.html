Learning Web Structure with HTML

HTML Tags - By Category

Tags grouped by purpose to help you find the right element for the job.

Document Structure

  • <!DOCTYPE> - Document type declaration
  • <html> - Root element of an HTML document
  • <head> - Container for metadata
  • <body> - Document body

Metadata

  • <base> - Base URL/target for links
  • <link> - External resource link (CSS, icons)
  • <meta> - Document metadata
  • <style> - Embedded CSS
  • <title> - Document title

Sectioning/Semantics

  • <header> - Introductory content
  • <nav> - Navigation links
  • <main> - Main content
  • <section> - Thematic grouping
  • <article> - Self-contained content
  • <aside> - Tangential content
  • <footer> - Footer content
  • <address> - Contact information

Text Content

  • <p> - Paragraph
  • <pre> - Preformatted text
  • <blockquote> - Long quotation
  • <hr> - Thematic break
  • <div> - Generic block container

Inline Text Semantics

  • <a> - Hyperlink
  • <abbr> - Abbreviation
  • <b>, <strong> - Attention/importance
  • <i>, <em> - Alternate voice/emphasis
  • <cite> - Cites a work
  • <code>, <samp>, <kbd> - Code, sample output, user input
  • <mark> - Highlighted text
  • <q> - Inline quotation
  • <small> - Side comments
  • <span> - Generic inline container
  • <sub>, <sup> - Subscript/superscript
  • <u> - Unarticulated annotation
  • <br>, <wbr> - Line/word break
  • <time> - Machine-readable time
  • <data> - Machine-readable value
  • <dfn> - Defining instance
  • <del>, <ins>, <s> - Edits/strikethrough

Lists

  • <ul> - Unordered list
  • <ol> - Ordered list
  • <li> - List item
  • <dl>, <dt>, <dd> - Description list/term/definition

Tables

  • <table>, <caption>
  • <thead>, <tbody>, <tfoot>
  • <tr>, <th>, <td>
  • <colgroup>, <col>

Forms

  • <form>, <fieldset>, <legend>
  • <label>, <input>, <textarea>, <button>
  • <select>, <optgroup>, <option>
  • <datalist>, <output>, <progress>, <meter>

Media

  • <img> - Image
  • <audio>, <video> - Media players
  • <source>, <track> - Media sources/tracks
  • <picture> - Responsive images
  • <map>, <area> - Image maps
  • <figure>, <figcaption> - Media with caption
  • <embed>, <object> - Embedded content
  • <iframe> - Inline frame

Scripting

  • <script> - Client-side script
  • <noscript> - Fallback content when scripts are disabled
  • <template> - Client-side template
  • <slot> - Web components slot

Interactive/Disclosure

  • <details> - Disclosure widget
  • <summary> - Summary for details
  • <dialog> - Dialog box

Ruby Annotations

  • <ruby> - Ruby annotation container
  • <rt> - Ruby text
  • <rp> - Ruby parentheses fallback
