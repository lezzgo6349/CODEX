Learning Web Structure with HTML

HTML Semantics

Semantic HTML uses elements that clearly describe their meaning in a human- and machine-readable way.

Instead of using generic <div> elements, semantic elements like <header>, <nav>, <main>, and <footer>
make your HTML more meaningful and accessible.

Why Use Semantic HTML?

  • Improves SEO (Search Engine Optimization) - search engines understand your content better
  • Better accessibility - screen readers can navigate your page more effectively
  • Easier to maintain - code is more readable and self-documenting
  • Future-proof - makes your HTML more maintainable as projects grow

Common Semantic Elements:

  • <header> - Defines a header for a document or section
  • <nav> - Defines navigation links
  • <main> - Specifies the main content of a document
  • <article> - Defines independent, self-contained content
  • <section> - Defines a section in a document
  • <aside> - Defines content aside from the main content
  • <footer> - Defines a footer for a document or section
  • <figure> and <figcaption> - Represents self-contained content with a caption
  • <time> - Represents a specific time or date
  • <mark> - Highlights text

Example - Semantic HTML Structure:

      
<!DOCTYPE html>
<html lang="en">
<head>
  <title>My Web Page</title>
</head>
<body>
  <header>
    <h1>Website Title</h1>
    <nav>
      <ul>
        <li><a href="#home">Home</a></li>
        <li><a href="#about">About</a></li>
        <li><a href="#contact">Contact</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <header>
        <h2>Article Title</h2>
        <p>Published on <time datetime="2024-01-15">January 15, 2024</time></p>
      </header>
      <section>
        <p>This is the main content of the article.</p>
        <figure>
          <img src="image.jpg" alt="Description">
          <figcaption>Image caption</figcaption>
        </figure>
      </section>
    </article>

    <aside>
      <h3>Related Links</h3>
      <ul>
        <li><a href="#">Link 1</a></li>
        <li><a href="#">Link 2</a></li>
      </ul>
    </aside>
  </main>

  <footer>
    <p>© 2024 My Website. All rights reserved.</p>
  </footer>
</body>
</html>

Example - Using Semantic Elements for Content:

      
<article>
  <header>
    <h2>How to Learn HTML</h2>
    <p>By John Doe</p>
  </header>

  <section>
    <p>HTML is the foundation of web development.</p>
    <mark>Start with the basics</mark> and practice regularly.
  </section>

  <footer>
    <p>Tags: HTML, Web Development, Learning</p>
  </footer>
</article>

Semantic vs Non-Semantic Elements:

  • Non-semantic: <div>, <span> - These elements tell us nothing about their content
  • Semantic: <form>, <table>, <article> - These elements clearly define their content
  • Use semantic elements when possible, but <div> and <span> are still useful for styling and layout

Best Practices:

  • Use <header> for introductory content, not just the page header
  • Use <main> only once per page for the primary content
  • Use <article> for content that could be distributed independently
  • Use <section> to group related content thematically
  • Combine semantic elements with proper heading hierarchy (<h1> to <h6>)
  • Use <nav> for navigation menus, not just any list of links
  • Add lang attribute to <html> for better accessibility
