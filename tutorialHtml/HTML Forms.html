Learning Web Structure with HTML

HTML Forms

An HTML Form is an area on a web page that collects user input and sends it to a server for processing.

Forms allow users to enter information such as their name, email address, passwords, comments, and more.

Main Elements of an HTML Form:

  • <form>: Container for all form elements
  • <input>: Defines fields for user input
  • <label>: Describes the input fields
  • <textarea>: For multi-line text input
  • <button>: Clickable button for submission and other actions
  • <select>: Drop-down list options

Basic Form Example: 

      
<form action="/submit" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name"><br>
    <label for="email">Email:</label>
    <input type="email" id="email" name="email"><br>
    <button type="submit">Send</button>
</form>

Common Form Fields:
• Text fields (type="text")
• Password fields (type="password")
• Email fields (type="email")
• Radio buttons, checkboxes
• Drop-down lists (<select>)
• Multi-line textareas

Best Practices:

  • Always use <label> tags linked to their inputs for better accessibility.
  • Make sure to set the method and action attributes on <form>.
  • Use type="email", "password", etc. for proper data handling.
  • Style your forms with CSS for better user experience.

Sample Grouped Form Example: 

      
<form action="/signup" method="post">
    <fieldset>
        <legend>Sign Up</legend>
        <label for="username">Username:</label>
        <input type="text" id="username" name="username"><br>
        <label for="pwd">Password:</label>
        <input type="password" id="pwd" name="pwd"><br>
        <label for="country">Country:</label>
        <select id="country" name="country">
            <option value="usa">USA</option>
            <option value="uk">UK</option>
        </select><br>
        <button type="submit">Register</button>
    </fieldset>
</form>
