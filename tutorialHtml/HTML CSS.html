Learning Web Structure with HTML

HTML CSS

CSS stands for Cascading Style Sheets and is the language used to describe the style and layout of HTML documents.

CSS controls how HTML elements look on the screen (color, size, position, fonts, spacing, and much more).

CSS Syntax: 

      
selector {
  property: value;
  property2: value2;
}

Parts of CSS:

  • Selector - the HTML element you want to style (e.g. p, .classname, #id)
  • Property - the style you want to change (e.g. color, font-size)
  • Value - what you want the property set to (e.g. blue, 18px)

Popular CSS Properties:

  • color - text color
  • background-color - background color
  • font-size - sets the size of the font
  • font-family - sets the font of the text
  • margin - adds space outside the element
  • padding - adds space inside the element
  • border - adds a border around the element
  • width, height - sets the width and height of the element

Three Ways to Include CSS in HTML:

  • Inline CSS: Use the style attribute directly in HTML elements.
  • Internal CSS: Place CSS rules inside a <style> block in the <head> section.
  • External CSS: Link to an external .css file using the <link> tag.

Examples:

Inline CSS 
      
<h1 style="color: orange;">Inline CSS Example</h1>
Internal CSS 
      
<head>
  <style>
     h1 {
       color: green;
     }
  </style>
</head>
External CSS 
      
<head>
  <link rel="stylesheet" href="styles.css">
</head>

Best Practices:

  • Use external CSS for large projects to separate design from structure.
  • Organize your styles using class and id selectors.
  • Keep CSS clean and readable.
