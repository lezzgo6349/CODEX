Learning Web Structure with HTML

HTML Tables

An HTML Table is a structured set of data made up of rows and columns, used to organize
  information on a web page.

Tables allow you to display information such as schedules, statistics, and comparison
  charts in a clear, logical format.

Main Elements of an HTML Table:

  • <table>: Defines the entire table
  • <tr>: Defines a row
  • <th>: Defines a header cell
  • <td>: Defines a data cell

Basic Table Example: 

            
<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Alice</td>
        <td>24</td>
    </tr>
    <tr>
        <td>Bob</td>
        <td>30</td>
    </tr>
</table>

When to Use Tables:
• Data grids
• Comparison lists
• Pricing and schedules
• Any structured/tabular data

Best Practices:

  • Use tables for tabular data only—not for layout.
  • Use <th> for headings to improve accessibility and styling.
  • Apply CSS to improve table appearance.

Grouped Table Example: 

            
<table border="1">
    <caption>Monthly Budget</caption>
    <thead>
        <tr>
            <th>Month</th>
            <th>Income</th>
            <th>Expenses</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Jan</td>
            <td>$1000</td>
            <td>$800</td>
        </tr>
        <tr>
            <td>Feb</td>
            <td>$1200</td>
            <td>$950</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>Total</td>
            <td>$2200</td>
            <td>$1750</td>
        </tr>
    </tfoot>
</table>
