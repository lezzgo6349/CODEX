Learning Web Structure with HTML

HTML Charsets

A character encoding (charset) tells the browser how to interpret and display characters in your HTML document.

It specifies which character set is being used, ensuring that text, symbols, and special characters display correctly
across different browsers and languages.

Why Use Character Encoding?

  • Ensures proper display of characters across all browsers and devices
  • Supports international characters and multiple languages
  • Prevents garbled or corrupted text display
  • Essential for displaying symbols, emojis, and special characters correctly
  • Required by HTML5 standards and improves SEO

Common Character Encodings:

  • UTF-8: The most widely used encoding (recommended by HTML5). Supports all Unicode characters and languages worldwide.
  • ISO-8859-1: Western European character set (legacy, largely replaced by UTF-8)
  • Windows-1252: Windows-specific encoding (legacy)
  • ASCII: Basic 128-character set (very limited, mostly historical)
  • UTF-16: Alternative Unicode encoding (less common for web pages)

Example - Declaring UTF-8 Charset (HTML5):

      
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Web Page</title>
</head>
<body>
  <h1>Welcome to My Website</h1>
  <p>This page supports multiple languages:</p>
  <p>English: Hello, World!</p>
  <p>Spanish: ¡Hola, Mundo!</p>
  <p>French: Bonjour, le monde!</p>
  <p>Chinese: 你好，世界！</p>
  <p>Japanese: こんにちは、世界！</p>
</body>
</html>

Example - Displaying Special Characters with UTF-8:

      
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Special Characters</title>
</head>
<body>
  <p>Currency: € £ ¥ $ ¢</p>
  <p>Mathematical: ∑ ∞ π ± × ÷</p>
  <p>Arrows: ← → ↑ ↓ ↔</p>
  <p>Emojis: 😀 🎉 💻 🌟 ❤️</p>
  <p>Symbols: © ® ™ ° ½ ¼ ¾</p>
</body>
</html>

Example - Legacy Encoding (Not Recommended):

      
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="ISO-8859-1">
  <title>Legacy Encoding</title>
</head>
<body>
  <p>Note: ISO-8859-1 only supports Western European characters.</p>
  <p>Special characters may not display correctly.</p>
</body>
</html>

How to Declare Charset in HTML:

  • HTML5 (Recommended): <meta charset="UTF-8"> in the <head> section
  • HTML4/XHTML: <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
  • The charset declaration should appear within the first 1024 bytes of your HTML document
  • Place it immediately after the opening <head> tag for best results

UTF-8 Advantages:

  • Supports all Unicode characters (over 1 million characters)
  • Backward compatible with ASCII
  • Works with all modern browsers and devices
  • Required for international websites and multi-language content
  • Efficient encoding - uses variable-length encoding (1-4 bytes per character)
  • Standard for modern web development

Best Practices:

  • Always use UTF-8 for new HTML documents
  • Declare charset in the <head> section as early as possible
  • Ensure your text editor saves files with UTF-8 encoding
  • Test your pages with special characters and emojis to verify encoding
  • Use lang attribute in <html> tag along with charset for better accessibility
  • When converting legacy sites, ensure all files use UTF-8 encoding
  • Verify charset matches your actual file encoding when editing
