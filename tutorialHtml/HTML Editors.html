Learning Web Structure with HTML

A simple text editor is all you need in order to learn the bases of HTML.

Step 1: (For PC Users) Open Notepad

Windows 8 or later:
Open the Start Screen ( the windows logo at the bottom left corner of your screen.)
Type Notepad.

Windows 7 or earlier:
Open Start ⟶ Programs ⟶ Accessories ⟶ Notepad

Step 2: Write Some HTML

Write or copy the following HTML code into Notepad:

    <!DOCTYPE html>
    <html>
    <head>
            <title> Title </title>
    </head>
    <body>
            <p> This is a paragraph. </p>
           <h1> This is heading 1 </h1>
    </body>
    </html>

Step 3: Save the HTML Page

Save the file on your computer. Select File ⟶ Save as in the Notepad menu.

Name the file "index.html" and set the encoding to UTF-8 (which is the preferred encoding for HTML files).

Tip: You can use either .htm or .html as file extension. There is absolutely no difference; it is up to you.

Step 4: View the HTML Page in Your Browser

Open the saved HTML file in your favorite browser
(double click on the file, or right-click - and choose "Open with").
