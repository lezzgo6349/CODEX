Learning Web Structure with HTML

HTML Attributes

• All HTML elements can have attributes.
• Attributes provide additional information about elements.

• Attributes are always specified in the opening tag.
• Attributes typically consist of a name and value pair, formatted as name="value".

The src Attribute

• The <img> tag is used to embed an image in an HTML page.
• The src attribute specifies the path to the image to be displayed:

<img src="home.png" alt="home">
•There are two ways to specify the URL in the src attribute:

• Absolute URL: to an external image hosted on another website.
Example: src="https://www.w3schools.com/images/img_girl.jpg".

  Notes: External images may be copyrighted, and using them without permission could violate copyright laws.

  Additionally, external images are outside your control and may be removed or altered unexpectedly.

• Relative URL: Points to an image hosted within the same website, omitting the domain name.

  – If the URL starts without a slash, it’s relative to the current page (e.g., src="../images/img_girl.jpg").
  – If it starts with a slash, it’s relative to the domain (e.g., src="/images/img_girl.jpg").

Tip: It is almost always best to use relative URLs. They will not break if you change domain.

The href Attribute

• The <a> tag defines a hyperlink. The href attribute specifies the URL of the page the link goes to:

<a href="https://www.facebook.com">  Go to Facebook  </a>

The width and height Attributes

• The <img> tag should also contain the width and height attributes,
   which specify the width and height of the image (in pixels):

<img src="img_girl.jpg"  width="200px"  height="400px">

The alt Attribute

• The required alt attribute for the tag specifies an alternate text for an image,
   if the image for some reason cannot be displayed.

• This can be due to a slow connection, or an error in the src attribute, or if the user uses a screen reader.

<img src="hoodie_girl.jpg"  alt="Girl with a Hoodie">

The style Attribute

• The style attribute is used to add styles to an element, such as color, font, size, and more.

<p style="color: yellow; " > This is a yellow paragraph. </p>

Always use Lowercase Attributes

• The HTML standard does not require lowercase attribute names.

• The body attribute (and all other attributes) can be written with uppercase or lowercase like body or BODY.

• However, Codex recommends lowercase attributes in HTML in order to avoid jumbled and messy structure.

Always Quote Attribute Values

• The HTML standard does not require quotes around attribute values.

• However, Codex recommends quotes in HTML, XHTML is strict and quoting is required.

Chapter Summary

• All HTML elements can have attributes
• The href attribute of <a> specifies the URL of the page the link goes to
• The src attribute of <img> specifies the path to the image to be displayed
• The width and height attributes of <img> provide size information for images
• The alt attribute of <img> provides an alternate text for an image
• The style attribute is used to add styles to an element, such as color, font, size, and more
• The lang attribute of the <html> tag declares the language of the Web page
• The title attribute defines some extra information about an element
