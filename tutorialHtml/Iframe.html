Learning Web Structure with HTML

HTML Iframe

• An HTML iframe is used to display a web page within a web page.
• The HTML <iframe> tag specifies an inline frame.

• An inline frame is used to embed another document within the current HTML document.
• Iframes are commonly used to embed maps, videos, or other external content.

Iframe Syntax

• The HTML <iframe> tag defines an inline frame.
• The src attribute specifies the URL of the page to embed:

<iframe src="URL"></iframe>

Iframe - Set Height and Width

• Use the height and width attributes to specify the size of the iframe.
• The height and width are specified in pixels by default:

<iframe src="demo_iframe.html" height="200" width="300"></iframe>

Iframe - Remove the Border

• By default, an iframe has a border around it.
• To remove the border, add the style attribute and use the CSS border property:

<iframe src="demo_iframe.html" style="border: none;"></iframe>
• You can also use CSS to change the size, style, and color of the iframe's border:
<iframe src="demo_iframe.html" style="border: 2px solid red;"></iframe>

Iframe - Target for a Link

• An iframe can be used as the target frame for a link.
• The target attribute of the link must refer to the name attribute of the iframe:

<iframe src="demo_iframe.html" name="iframe_a"></iframe>
<p><a href="https://www.example.com" target="iframe_a">Example.com</a></p>

Iframe Attributes

• src: Specifies the URL of the page to embed in the iframe.

• width: Specifies the width of the iframe in pixels or percentage.

• height: Specifies the height of the iframe in pixels or percentage.

• name: Specifies a name for the iframe (useful for targeting).

• title: Specifies extra information about the iframe (useful for accessibility).

• sandbox: Enables an extra set of restrictions for the content in the iframe.

• loading: Specifies whether a browser should load an iframe immediately or defer loading until certain conditions are met.

Common Uses of Iframes

• Embedding Maps: Display Google Maps or other mapping services on your website.

• Embedding Videos: Include YouTube, Vimeo, or other video content.

• Embedding Social Media: Show Twitter feeds, Facebook posts, or Instagram embeds.

• Embedding Documents: Display PDFs or other documents within your page.

• Creating Widgets: Embed third-party widgets or calculators.

Chapter Summary

• The HTML <iframe> tag specifies an inline frame
• The src attribute defines the URL of the page to embed
• Always include a title attribute (for screen readers)
• The height and width attributes are used to specify the size of the iframe
• Use CSS border property to remove the iframe border or style it
• The name attribute allows the iframe to be used as a target for a link
• Iframes are useful for embedding external content like maps, videos, and documents
