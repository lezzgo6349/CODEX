Learning Web Structure with HTML

HTML Media

HTML Media refers to multimedia elements that can be embedded in web pages, such as images, audio, and video.

These elements help to enhance the user experience and deliver richer content.

Main HTML Media Tags:

  • <img>: Embeds images
  • <audio>: Embeds sound/audio files
  • <video>: Embeds video files
  • <source>: Specifies media sources for <audio> and <video>
  • <track>: Defines text tracks (like subtitles) for <video>

Common Attributes:

  • src: Specifies the media file path
  • alt: Provides alternative text for <img>
  • controls: Adds play/pause controls for <audio> and <video>
  • autoplay: Starts playing media automatically
  • loop: Repeats the media content
  • muted: Mutes audio by default
  • width / height: Sets the size for images and videos
  • poster: Specifies an image to show before a video plays

Basic Media Examples: 

      
<img src="cat.jpg" alt="A cute cat" width="200">

<audio src="music.mp3" controls></audio>

<video width="320" height="240" controls>
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.ogg" type="video/ogg">
    Your browser does not support the video tag.
</video>

Tips & Best Practices:

  • Always use alt text for images (for accessibility).
  • Provide multiple <source> files for better browser compatibility.
  • Use controls for user-friendly playback.
  • Keep media file sizes optimized for faster loading.
  • Consider subtitles and captions for video accessibility using <track>.

Sample Video Tag with Track: 

      
<video width="420" height="340" controls>
    <source src="sample.mp4" type="video/mp4">
    <track src="captions_en.vtt" kind="subtitles" srclang="en" label="English">
</video>
