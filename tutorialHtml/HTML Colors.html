HTML Colors

You can define colors in HTML/CSS using color names, HEX codes, RGB/RGBA, HSL/HSLA, and more.

Below is a list of commonly used color names with their HEX and RGB values, plus examples of other formats.

Basic Color Formats:

  • Color Names — e.g., red, blue, goldenrod
  • HEX — #RRGGBB or shorthand #RGB (e.g., #FF0000)
  • RGB — rgb(255, 0, 0)
  • RGBA — rgba(255, 0, 0, 0.5) (with alpha/opacity)
  • HSL — hsl(0, 100%, 50%)
  • HSLA — hsla(0, 100%, 50%, 0.5)

Usage Example:

        
<div style="color: white; background-color: #1E90FF; padding: 10px;">HEX: #1E90FF</div>
<div style="color: white; background-color: rgb(220, 20, 60); padding: 10px;">RGB: rgb(220, 20, 60)</div>
<div style="color: white; background-color: hsl(120, 60%, 40%); padding: 10px;">HSL: hsl(120, 60%, 40%)</div>
<div style="color: white; background-color: rgba(0, 0, 0, 0.6); padding: 10px;">RGBA: rgba(0,0,0,0.6)</div>

Tips:

  • Prefer HEX or HSL for palettes; use RGBA/HSLA for transparency.
  • Keep adequate contrast for accessibility (WCAG).
  • Consistently use either American or British spelling for Gray/Grey in code.
