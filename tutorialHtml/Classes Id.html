Learning Web Structure with HTML

Classes and IDs in HTML

class and id are attributes used to identify and style HTML elements.

They help you target specific elements with CSS and JavaScript, making your web pages more organized and interactive.

What is class?

  • The class attribute can be used on multiple elements
  • Multiple classes can be applied to a single element (separated by spaces)
  • Used for styling groups of similar elements
  • Identified in CSS with a dot (.) prefix

What is id?

  • The id attribute must be unique on each page
  • Only one element can have a specific id value per page
  • Used for targeting single, specific elements
  • Identified in CSS with a hash (#) prefix

Example - Using Classes:

      
<p class="highlight important">This paragraph has two classes!</p>
<p class="highlight">This paragraph has one class.</p>
<div class="highlight">This div shares the same class.</div>

<style>
  .highlight {
    background-color: yellow;
  }
  .important {
    font-weight: bold;
  }
</style>

Example - Using IDs:

      
<div id="header">This is the header section</div>
<div id="main-content">This is the main content</div>
<button id="submitBtn">Submit</button>

<style>
  #header {
    background-color: #333;
    color: white;
  }
  #main-content {
    padding: 20px;
  }
</style>

Combining Classes and IDs:

      
<div id="container" class="wrapper box">
  <p class="text" id="intro-text">Welcome to our website!</p>
</div>

<style>
    #container {
      background-color: #838181;
      padding: 25px;
      width: 400px;
    }
    .wrapper {
      background-color: #f9f9f9;
      padding: 18px;
    }
    .box {
      box-shadow: #353434;
      padding: 18px;
    }
    .text {
      color: #050505;
    }
    #intro-text {
      text-decoration: underline;
    }
  </style>

Key Differences:

  • class is reusable—multiple elements can share the same class
  • id is unique—only one element per page can have a specific id
  • Use class for styling similar elements together
  • Use id for JavaScript targeting and anchor links
  • An element can have multiple classes but only one id

Best Practices:

  • Use descriptive names that indicate purpose (e.g., class="button-primary" not class="blue")
  • Keep id values unique across your entire page
  • Prefer classes for styling unless you specifically need an id
  • Use kebab-case (hyphens) for naming: class="main-header" instead of class="mainHeader"
  • IDs can be used for anchor links (e.g., #section1 in URLs)
