Learning Web Structure with HTML

HTML Documents

• All HTML documents must start with a document type declaration: <!DOCTYPE html>.

• The HTML document itself begins with <html> and ends with </html>.

• The visible part of the HTML document is between <body> and </body>.

Example

The <!DOCTYPE> Declaration

• The <!DOCTYPE> represents the document type on which it helps browsers display web pages correctly.
    Must appear only once, always at the top of the page.

• The <!DOCTYPE> declaration is not case sensitive.
• The <!DOCTYPE> declaration is presented as:

<!DOCTYPE html>

The <html> tag

• The <html> tag is found after the <!DOCTYPE> declaration.
• It is the root element of an HTML Document. It contains all other elements, like <head> and <body>,
    and defines the document as HTML

Example:

The <head> tag

• The <head> tag isused to contain metadata and other non-visible elements
that provide information about the document or link to resources needed for the page. It sits inside
the <html> tag and typically comes before the <body> tag.

• The <head> tag includes:

<meta charset="UTF-8">: Sets character encoding.
<meta name="viewport">: Ensures responsive design.
<meta name="description">: Provides a page description for SEO.
<title>: Sets the browser tab title.
<link><link>: Links an external CSS file.
<script><script>: Links an external JavaScript file.

The <body> tag

• The <body> tag in HTML defines the main content of a webpage that is visible to users in the browser.

• It contains all the elements that make up the page’s structure and content, such as text, images, headings,
   paragraphs, links, forms, and more.

• The <body> tag contains the visible content of a webpage, including:

Text: Headings (<h1> ⟶ <h6>), paragraphs (<p>), etc.
Media : Images (<img>), videos (<video>), audio (<audio>).
Links: Hyperlinks (<a>).
Structure: Containers like <div>, <section>, <header>, <footer>.
Other: Lists (<ul>, <ol>), tables (<table>), etc.
