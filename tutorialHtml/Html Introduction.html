Learning Web Structure with HTML

What is HTML?

• HTML stands for Hyper Text Markup Language
• HTML is the standard markup language for creating and structuring web content.
• HTML is not a programming language; focuses on content structure, not logic.
• HTML files (.html) are rendered by browsers to display formatted web pages.
• HTML consists of a series of elements

A Simple Document Example

Examples Explained

• The <!DOCTYPE html> declaration defines that this document is an HTML5 document
• The <html> element is the root element of an HTML page
• The <head> element contains meta information about the HTML page
• The <title> element specifies a title for the HTML page.
• The <body> element defines the document's body.
• The <h1> & <h2> elements define headings.
• The <p> element defines a paragraph.

HTML History

• World Wide Web (1989): Tim Berners-Lee proposed a system to share and link information across computers globally.

• HTML 1.0 (1990): Basic tags for text, headings, and links.

• HTML 2.0 (1995): Added forms, tables, and images.

• HTML 3.2 (1997): Better tables, text wrapping around images.

• HTML 4.0 / 4.01 (1997–1999): Added CSS and accessibility.

• HTML5 (2014): Added semantic tags, video/audio, and mobile support.

• HTML Living Standard (Ongoing): Continuously updated to modern needs.
