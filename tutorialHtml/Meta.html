Learning Web Structure with HTML

HTML Meta Tags

• The HTML <meta> tag defines metadata about an HTML document.
• Metadata is data (information) about data.

• <meta> tags always go inside the <head> element.
• Meta tags are used to specify character set, page description, keywords, author of the document, and viewport settings.

Meta Tags Syntax

• The HTML <meta> tag is an empty element and contains only attributes.
• Metadata is not displayed on the page, but is machine parsable.
• Meta tags are used by browsers, search engines, and other web services:

<meta charset="UTF-8">
<meta name="description" content="Free HTML tutorials">
<meta name="keywords" content="HTML, CSS, JavaScript">
<meta name="author" content="John Doe">
<meta name="viewport" content="width=device_width, initial_scale=1.0">

Specify Character Set

• The charset attribute specifies the character encoding for the HTML document.
• UTF-8 character set covers almost all characters and symbols in the world.
• If not specified, the default character set for HTML5 is UTF-8:

<meta charset="UTF-8">

Define a Description of Your Web Page

• The name attribute with the value description defines the description of your web page.
• This description is often used by search engines to display a snippet of your page in search results:

<meta name="description" content="Free web tutorials on HTML and CSS">

Define Keywords for Search Engines

• The name attribute with the value keywords defines keywords for search engines.
• Note: Some search engines no longer use this meta tag:

<meta name="keywords" content="HTML, CSS, JavaScript, Web Development">

Define the Author of a Page

• The name attribute with the value author defines the author of the web page:

<meta name="author" content="John Doe">

Refresh Document Every 30 Seconds

• The http-equiv attribute with the value refresh defines a time interval for the document to refresh itself.
• The content attribute must contain the number of seconds:

<meta http_equiv="refresh" content="30">

Setting the Viewport

• The viewport is the user's visible area of a web page.
• It varies with the device - it will be smaller on a mobile phone than on a computer screen.
• You should include the following <meta> viewport element in all your web pages:

<meta name="viewport" content="width=device_width, initial_scale=1.0">
• This gives the browser instructions on how to control the page's dimensions and scaling.

• width=device-width: Sets the width of the page to follow the screen-width of the device.
• initial-scale=1.0: Sets the initial zoom level when the page is first loaded by the browser.

Common Meta Tags

• charset: Specifies the character encoding for the document.

• description: Provides a brief description of the web page.

• keywords: Specifies keywords for search engines (less important now).

• author: Defines the author of the document.

• viewport: Controls the page's dimensions and scaling on different devices.

• robots: Tells search engines which pages to index and follow.

• theme-color: Sets the theme color for the browser UI.

Importance of Meta Tags

• SEO: Help search engines understand and rank your website better.

• Social Media: Control how your pages appear when shared on social platforms (using Open Graph tags).

• Mobile Responsiveness: The viewport meta tag is essential for responsive web design.

• Character Encoding: Ensures your content displays correctly in all browsers.

• Browser Behavior: Can control caching, refresh rates, and other browser behaviors.

Chapter Summary

• The HTML <meta> tag defines metadata about an HTML document
• Metadata will not be displayed on the page, but is machine parsable
• Meta tags are always placed inside the <head> element
• Use charset to specify the character encoding (UTF-8 is recommended)
• Use name and content attributes to define metadata
• The viewport meta tag is essential for responsive web design
• Meta tags are important for SEO, social media sharing, and browser behavior
